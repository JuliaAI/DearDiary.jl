Quickstart

This page tracks one run end to end on a local database, with no server and no extra packages. For remote logging see Log from a remote client.

Open the local database. It is created on first use.

using DearDiary
DearDiary.initialize_database()

Create a project and an experiment to hold the runs.

julia> project_id, _ = create_project("Iris classification")(id = "0484e54a-c44b-4040-a646-3ed508ef514f", status = DearDiary.Created)
julia> experiment_id, _ = create_experiment(project_id, DearDiary.IN_PROGRESS, "Decision-tree sweep")(id = "5921bd46-799c-42eb-b6ad-0d4e732c4762", status = DearDiary.Created)

Open an iteration and log parameters and metrics. with_iteration marks the iteration SUCCEEDED on a clean return or FAILED on a throw, and snapshots the environment.

julia> with_iteration(experiment_id) do iter
           create_parameter(iter.id, "max_depth", 7)
           create_metric(iter.id, "accuracy", 0.96)
       end(id = "cec20e83-901f-401b-9eb6-3ecba5206f4b", status = DearDiary.Created)

Read the logged data back.

julia> get_parameters(iteration.id)1-element Vector{DearDiary.Parameter}:
 Parameter(max_depth = "7")
julia> get_metrics(iteration.id)1-element Vector{DearDiary.Metric}:
 Metric(accuracy = 0.96, step = 0)

A list prints one record per line, and a single record prints every field. Each list is also a Tables.jl table, so DataFrame(get_metrics(iteration.id)) or pretty_table(get_metrics(iteration.id)) work once DataFrames.jl or PrettyTables.jl is loaded.
